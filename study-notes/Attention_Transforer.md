# 어텐션(Attention)과 트랜스포머(Transformer)

## 어텐션 메커니즘
    어텐션은 이름 그대로, 모델이 입력 시퀀스의 특정 부분에 더 집중하게 만드는 메커니즘입니다. 
    마치 우리가 문장을 읽을 때 모든 단어에 동일한 비중을 두지 않고, 문맥상 중요한 단어에 더 주의를 기울이는 것과 같습니다.

## 기존 모델의 한계
    어텐션이 등장하기 전, 번역이나 요약과 같은 작업에는 주로 순환 신경망(RNN) 기반의 Seq2Seq 모델이 사용되었습니다. 
    이 모델은 입력 문장을 하나의 고정된 크기의 벡터(Context Vector)로 압축하고, 이 벡터를 이용해 출력 문장을 생성했습니다. 하지만 이 방식은 입력 문장이 길어질수록 초반부의 정보가 손실되는 **장기 의존성 문제(Long-term Dependency Problem)**를 가지고 있었습니다. 문장이 길어지면, 문장 끝 단어를 번역할 때쯤엔 이미 문장 맨 앞 단어의 의미는 희미해지는 것이죠.


## 어텐션의 해결책
    어텐션은 이러한 한계를 극복하기 위해 디코더가 매 타임스텝마다 인코더의 모든 출력에 다시 접근하여 관련성이 높은 정보에 가중치를 부여하는 방식을 제안했습니다.

  쿼리(Query): 현재 디코더가 주목해야 할 정보에 대한 질문입니다. 즉, "다음에 생성할 단어는 어떤 정보와
  관련이 있을까?" 라는 질문이라고 할 수 있습니다.
  키(Key): 입력 시퀀스의 각 단어들이 가지고 있는 고유한 식별자입니다.
  값(Value): 입력 시퀀스의 각 단어들이 가지고 있는 실제 의미 내용입니다.

어텐션은 현재의 쿼리와 모든 키를 비교하여 유사도를 계산하고, 이 유사도를 바탕으로 각 값에 대한 어텐션 가중치(Attention Weight)를 구합니다. 그리고 이 가중치를 각 값(Value)에 곱한 후 모두 더하여 최종적인 결과, 즉 현재 시점에서 가장 중요한 정보가 담긴 컨텍스트 벡터(Context Vector)를 만들어냅니다.


## 트랜스포머(Transformer)


## 트랜스포머의 주요 구성 요소

1. 셀프 어텐션(Self-Attention): 트랜스포머의 핵심 개념으로, 어텐션 메커니즘을 자기 자신에게 적용하는 방식입니다. 즉, 문장 내의 단어들이 서로 어떤 관계를 맺고 있는지, 어떤 단어가 다른 단어에 더 큰 영향을 미치는지를 파악합니다.

2. 멀티-헤드 어텐션(Multi-Head Attention): 셀프 어텐션을 한 번만 수행하는 것이 아니라, 여러 개의 헤드(Head)를 두어 병렬적으로 여러 번 수행하는 방식입니다. 각 헤드는 문장의 서로 다른 측면(예: 문법적 관계, 의미적 관계 등)에 집중하여 정보를 학습합니다.

3. 포지셔널 인코딩 (Positional Encoding): 트랜스포머는 단어를 순차적으로 처리하지 않기 때문에, 각 단어의 위치 정보를 따로 알려주어야 합니다. 포지셔널 인코딩은 사인(Sin)과 코사인(Cosine) 함수를 이용해 각 단어의 절대적인 위치와 상대적인 위치 정보를 벡터 형태로 만들어 입력 임베딩에 더해주는 역할을 합니다. 이를 통해 모델은 단어의 순서를 인지할 수 있게 됩니다.

4. 인코더-디코더 구조 (Encoder-Decoder Structure): 트랜스포머는 크게 인코더와 디코더 두 부분으로 나뉩니다.

   인코더(Encoder): 입력 문장을 받아들여 문맥 정보를 압축한 표현(representation)을 만듭니다. 여러 개의 인코더 레이어로 구성되며, 각 레이어는 셀프 어텐션과 피드 포워드 신경망으로 이루어져 있습니다.

  디코더(Decoder): 인코더가 생성한 표현과 이전에 생성된 출력 단어들을 이용해 다음 단어를 예측하고 최종 출력 문장을 생성합니다. 디코더 역시 여러 개의 레이어로 구성되며, 인코더의 셀프 어텐션 외에 인코더-디코더 어텐션 레이어가 추가로 존재합니다.
