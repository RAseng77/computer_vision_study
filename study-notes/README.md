# 활성화 함수: ReLU
ReLU는 입력값이 0보다 크면 그 값을 그대로 출력하고, 0보다 작거나 같으면 0을 출력하는 간단한 형태의 함수
수식:  f(x)=max(0,x)
장점:
      계산 속도: 시그모이드나 tanh에 비해 계산이 훨씬 빠릅니다.
      기울기 소실 문제 완화: 시그모이드나 tanh는 입력값이 커지거나 작아질수록 미분값이 0에 가까워
      져서 학습이 제대로 이뤄지지 않는 기울기 소실(vanishing gradient)문제가 발생할 수 있습니다.
      ReLU는 양의 영역에서 미분값이 항상 1이므로 이 문제를 완화할 수 있습니다.
