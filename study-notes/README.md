# AlexNet
## 활성화 함수: ReLU
ReLU는 입력값이 0보다 크면 그 값을 그대로 출력하고, 0보다 작거나 같으면 0을 출력하는 간단한 형태의 함수
수식:  f(x)=max(0,x)
장점:
      계산 속도: 시그모이드나 tanh에 비해 계산이 훨씬 빠릅니다.
      기울기 소실 문제 완화: 시그모이드나 tanh는 입력값이 커지거나 작아질수록 미분값이 0에 가까워
      져서 학습이 제대로 이뤄지지 않는 기울기 소실(vanishing gradient)문제가 발생할 수 있습니다.
      ReLU는 양의 영역에서 미분값이 항상 1이므로 이 문제를 완화할 수 있습니다.

## Dropout
드롭아웃은 학습 과정에서 과적합(overfitting)을 방지하기 위해 사용되는 정규화(regularization) 기법입니다.
학습 시, 특정 확률(예: 0.5)로 뉴런을 임시적으로 비활성화하여 네트워크가 특정 뉴런에 과도하게 의존하는것을 방지한다.

## Overlapping Pooling
일반적인 풀링은 겹치지 않는 영역에서 최대값이나 평균값을 추출하는 반면, AlexNet은 겹치는 영역에서 풀링을 수행했습니다. 예를 들어, 일반적으로 2x2 크기 풀링을 스트라이드(stride) 2로 사용했다면,
AlexNet은 3x3 크기 풀링을 스트라이드 2로 사용했습니다.
효과:
      과적합 방지: 중첩 풀링은 모델이 미세한 위치 변화에 덜 민감해지도록 하여 과적합을 줄이는 데       도움이 됩니다.

## Local Response Normalization(LRN)
LRN은 특정 뉴런의 활성화 값에 인접한 뉴런들의 활성화 값들을 고려하여 정규화하는 기법입니다.
이는 시작 피질의 측면 억제(lateral inhibition)현상에서 영감을 얻었으며, 강하게 활성화된 뉴런이 주변 뉴런들을 억제하는 효과를 흉내냅니다.

효과: 이웃한 특징 맵들 간의 경쟁을 유도하여 특징의 강조(enhancement)효과를 가져오고, 모델의 일반화 성능을 높이는 데 기여했습니다. 하지만 현재는 배치 정규화(Batch Normalization)와 같은 더 효율적인 정규화 기법이 널리 사용되면서 LRN은 잘 쓰이지 않습니다.

## Softmax 함수
소프트맥스 함수는 신경망의 마지막 출력 레이어에서 사용되는 활성화 함수로, 여러 개의 입력값을 받아서 그 값들을 확률 분포로 변환해줍니다.
