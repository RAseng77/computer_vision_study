# AlexNet
## 활성화 함수: ReLU
      ReLU는 입력값이 0보다 크면 그 값을 그대로 출력하고, 0보다 작거나 같으면 0을 출력하는 간단한 형태의 함수
      수식:  f(x)=max(0,x)
      장점:
            계산 속도: 시그모이드나 tanh에 비해 계산이 훨씬 빠릅니다.
            기울기 소실 문제 완화: 시그모이드나 tanh는 입력값이 커지거나 작아질수록 미분값이 0에 가까워
            져서 학습이 제대로 이뤄지지 않는 기울기 소실(vanishing gradient)문제가 발생할 수 있습니다.
            ReLU는 양의 영역에서 미분값이 항상 1이므로 이 문제를 완화할 수 있습니다.

## Dropout
      드롭아웃은 학습 과정에서 과적합(overfitting)을 방지하기 위해 사용되는 정규화(regularization) 기법입니다.
      학습 시, 특정 확률(예: 0.5)로 뉴런을 임시적으로 비활성화하여 네트워크가 특정 뉴런에 과도하게 의존하는것을 방지한다.

## Overlapping Pooling
      일반적인 풀링은 겹치지 않는 영역에서 최대값이나 평균값을 추출하는 반면, AlexNet은 겹치는 영역에서 풀링을 수행했습니다. 예를 들어, 일반적으로 2x2 크기 풀링을 스트라이드(stride) 2로 사용했다면,
      AlexNet은 3x3 크기 풀링을 스트라이드 2로 사용했습니다.
      효과:
            과적합 방지: 중첩 풀링은 모델이 미세한 위치 변화에 덜 민감해지도록 하여 과적합을 줄이는 데       도움이 됩니다.

## Local Response Normalization(LRN)
      LRN은 특정 뉴런의 활성화 값에 인접한 뉴런들의 활성화 값들을 고려하여 정규화하는 기법입니다. 이는 시작 피질의 측면 억제(lateral inhibition)현상에서 영감을 얻었으며, 강하게 활성화된 뉴런이 주변 뉴런들을 억제하는 효과를 흉내냅니다.

      효과: 이웃한 특징 맵들 간의 경쟁을 유도하여 특징의 강조(enhancement)효과를 가져오고, 모델의 일반화 성능을 높이는 데 기여했습니다. 하지만 현재는 배치 정규화(Batch Normalization)와 같은 더 효율적인 정규화 기법이 널리 사용되면서 LRN은 잘 쓰이지 않습니다.

## Softmax 함수
      소프트맥스 함수는 신경망의 마지막 출력 레이어에서 사용되는 활성화 함수로, 여러 개의 입력값을 받아서 그 값들을 확률 분포로 변환해줍니다. 

# VGGNet
      VGGNet은 깊이를 늘리는 것이 성능 향상에 중요하다는 것을 보여준 모델입니다.

## 구조 및 특징:
      작은 필터의 반복: 3x3 크기의 작은 컨볼루션 필터와 2x2 크기의 맥스 풀링만을 반복적으로 사용하여 네트워크를 매우 깊게 만들었습니다.

      깊은 네트워크: 16개 또는 19개의 레이어로 구성되어, 당시로는 매우 깊은 모델이었습니다. 3x3 필터를 여러 층 쌓는 것은 5x5 나 7x7 필터 한 개를 사용하는 것과 같은 수용 영역(receptive field)을 가지면서도 파라미터 수를 줄이고, 비선형성을 더 많이 추가하는 효과를 냈습니다.

      장점:
            구조의 단순성, 전이 학습에 용이
      단점: 높은 파라미터수 -> 마지막 연결 레이어의 파라미터 수가 매우 많아 모델 크기가 크고 메모리 사용량이 많습니다. 이 때문에 계산 비용이 높습니다.


# GoogLeNet(InceptionNet)
      GoogLeNet은 네트워크의 깊이와 너비를 모두 확장하면서도 계산 효율성을 극대화한 모델입니다.

## 구조 및 특징:
      인셉션 모듈(Inception Module): 이 모델의 핵심 아이디어입니다. 하나의 레이어에서 다양한 크기의 필터(1x1, 3x3, 5x5)와 풀링 연산을 병렬로 수행하고, 그 결과를 모두 합쳐(concatenate) 다음 레이어로 전달합니다.

      1x1 컨볼루션: 인셉션 모듈 내에서 1x1 컨볼루션을 사용하여 채널 수를 줄이는 차원 축소를 수행합니다. 이는 파라미터 수를 획기적으로 줄여 계산량을 감소 시키는 중요한 역할을 합니다.

      보조 분류기: 깊은 네트워크에서 발생할 수 있는 기울기 소실 문제를 완화하기 위해 네트워크의 중간 단계에 보조 분류기를 추가했습니다. 학습 시 중간 손실을 계산하여 역전파를 돕는 역할을 합니다.

      장점: 낮은 파라미터 수 -> 인셉션 모듈과 1x1 컨볼루션을 통해 파라미터 수를 줄임
            높은 계산 효율성

      단점: 복잡한 구조 -> 인셉션 모듈의 구조를 이해하고 구현하는 데 어려움이 있을 수 있음


# ResNet
    ResNet은 잔차 연결 또는 스킵 연결을 핵심 아이디어로 사용합니다.\

## 특징 및 구조:
        잔차학습: ResNet은 신경망이 입력 x를 목표값 H(x)로 매핑하는 함수를 직접 학습하는 대신, 입력과 출력의 차이인 잔차(Residual) F(x) = H(x) - x 를 학습하도록 설계 되었습니다.

        스킵연결:입력 x가 여러 층을 거쳐 출력될 때, 그 출력에 다시 원래의 입력 x를 더해주는 구조를 가집니다. 이를 통해 정보와 기울기가 깊은 층에서도 손실 없이 전파되어 기울기 소실 문제를 완화합니다.

        블록 구성: 여러 층을 묶은 잔차 블록(Residual Block)을 쌓아 전체 네트워크를 구성합니다. 만약 입력과 출력의 차원이 다르면, 1x1 컨볼루션 레이어를 사용해 차원을 맞춰줍니다.

# DenseNet
    DenseNet은 ResNet의 스킵 연결을 더욱 확장한 개념으로, 모든 이전 층의 특징 맵(Feature Map)을 다음층의 입력으로 연결합니다.

## 특징 및 구조:
    밀집 연결(Dense Connectivity): 각 층은 바로 이전 층의 출력만 받는 것이 아니라, 앞선 모든 층의 출력을 채널 차원으로 합쳐서(Concatenation) 입력으로 받습니다. 이로 인해 L개의 층이 있는 네트워크는 L(L+1)/2개의 연결을 가집니다.

    특징 재사용(Featuree Reuse): 모든 층이 이전 층들의 풍부한 특징 맵에 접근할 수 있어, 정보 흐름을 극대화하고 특징 재사용을 촉진합니다. 이 덕분에 적은 수의 파라미터로도 높은 성능을 달성할 수 있습니다.

    블록 구성:밀집 블록(Dense Block)과 전환 층(Transition Layer)으로 구성됩니다. 밀집 블록내에서는 모든 층이 서로 연결되고, 전환 층은 컨볼루션과 풀링을 사용해 특징 맵의 크기를 줄이고 파라미터 수를 효율적으로 관리합니다.

# EfficientNet
    EfficientNet은 깊이(Depth, 층의 수), 너비(Width, 채널의 수), 해상도(Resolution, 입력 이미지 크기)를 균형 있게 동시에 확장하는 모델

## 복합 스케일링 (Compound Scaling)
    깊이(Depth) 스케일링: 층을 더 깊게 쌓으면 모델이 더 복잡한 특징을 학습할수 있음, 하지만 기울기 소실 문제나 계산량 증가를 야기함
    너비(Width) 스케일링: 채널 수를 늘리면 각 층이 더 풍부한 특징을 포착할 수 있지만, 너무 넓은 네트워크는 비효율적일 수 있음
    해상도(Resolution) 스케일링: 입력 이미지의 해상도를 높이면 더 세밀한 특징을 학습할 수 있지만, 계산량이 기하급수적으로 증가함.

EfficientNet은 하나의 복합 계수(ϕ)를 사용하여 이 세 가지 차원을 동시에 조절합니다.

# MobileNet
    MobileNet은 효율적인 연산을 위해 깊이별 분리 가능 합성곱을 핵심 기술로 사용합니다.

## 특징
    깊이별 합성곱(Depthwise Convolution): 각 입력 채널에 대해 독립적으로 하나의 필터를 적용하여 공간적 정보를 학습합니다.
    점별 합성곱(Pointwise Convolution): 1x1 컨볼루션을 사용하여 앞서 생성된 모든 채널의 출력 특징맵을 결합하고 새로운 특징 맵을 생성합니다.
