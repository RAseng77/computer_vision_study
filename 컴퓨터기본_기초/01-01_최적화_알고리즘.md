# Deep Learning Optimization Algorithm의 중요성
* 딥러닝 모델을 학습시킬 때, 최적화 알고리즘(Optimizer)은 매우 핵심적인 역할을 합니다. 이는 모델의 성능, 학습 속도, 일반화 능력 모두에 직결되기 때문이에요

## 1. Performance Optimization(성능 향상)
* 설명: 최적화 알고리즘은 모델이 학습 데이터를 잘 학습해서 더 높은 정확도(accuracy)나 성능을 내도록 도와줍니다.
* 이유::
  * 모델의 가중치(Weights)를 반복적으로 업데이트하면서 손실 함수(Loss)를 최소화하는 방향으로 학습시킵니다.
  * SGD, Adam, RMSProp 같은 알고리즘이 이런 역할을 합니다.
* 예시:
  * 같은 신경망 구조라도, Adam을 쓰면 SGD보다 빠르게 좋은 성능을 내는 경우가 많습니다.
 
## 2. Efficient Learning Process (학습 속도 향상)
* 설명: 최적화 알고리즘은 학습 과정을 더 효율적으로 만들어서, 모델이 빠르게 좋은 성능에 도달할 수 있도록 합니다.
* 이유:
  * 학습률(Learning Rate) 조정, 모멘텀(Momentum), 적응형 학습률(Adaptive Learning Rate) 같은 기법들이 불필요한 계산 낭비를 줄이고 최적값에 빠르게 접근하게 됩니다.
* 예시:
  * Adam은 파라미터마다 학습률을 다르게 조정하기 때문에 학습 초기에도 빠르게 수렴합니다.
  * 반대로 단순 SGD는 같은 학습률로 모든 파라미터를 업데이트 하기 때문에 시간이 더 오래 걸릴 수 있습니다.
 
## 3. Stability and Convergence(안정성과 수렴, 과적합 방지)
* 설명: 최적화 알고리즘은 모델이 안정적으로 학습하도록 돕고, 단순히 훈련 데이터만 외우는 과적합(Overfitting)을 막아줍니다.
* 이유:
  * 적절한 최적화 알고리즘은 진짜 패턴을 잘 찾아내고, 불필요한 진동(oscillation)이나 발산(divergence)을 방지합니다.
  * 정규화 기법(L2 Regularization, Dropout)과 함께 쓰이면 더 안정적인 일반화가 가능합니다.
* 예시:
  * 학습률이 너무 크면 Loss가 발산해서 성능이 불안정해집니다.
  * Adam이나 RMSProp 같은 최적화기는 이런 상황에서도 비교적 안정적으로 수렴할 수 있도록 설계되어 있습니다.


### 1. GD(Gradient Descent, 경사 하강법)
* 모든 데이터를 다 보고(Full Batch) 기울기를 계산해서 이동하는 방식
* 장점: 정확하지만 시간이 오래 걸림
* 비유: "지도 전체를 확인하고 한 걸을씩 가는 탐험가."

## 2. SGD(Stochastic Gradient Descent, 확률적 경사 하강법)
* 전체 데이터를 다 보는 대신 일부 샘플(배치)만 보고 빠르게 방향을 정함
* 장점: 학습 속도가 빨라짐eep Learning Optimization Algorithm의 중요성

### 1. GD(Gradient Descent, 경사 하강법)
* 모든 데이터를 다 보고(Full Batch) 기울기를 계산해서 이동하는 방식
* 장점: 정확하지만 시간이 오래 걸림
* 비유: "지도 전체를 확인하고 한 걸을씩 가는 탐험가."

### 2. SGD(Stochastic Gradient Descent, 확률적 경사 하강법)
* 전체 데이터를 다 보는 대신 일부 샘플(배치)만 보고 빠르게 방향을 정함
* 장점: 학습 속도가 빨라짐
* 단점: 기울기가 들쭉날쭉해서 불안정할 수 있음
* 비유: "전체 길 대신 주변만 보고 빨리빨리 걸어감"

### 3. Momentum
* 이동할 때 관성(이전 방향)을 고려해서 더 매끄럽게, 빠르게 이동
* 장점: 진동을 줄이고, 낭비되는 움직임을 억제
* 비유: "언덕에서 내려오면 관성 때문에 더 잘 굴러감."

### 4. NAG(Nesterov Accelerated Gradient)
* Momentum보다 한 단계 더발전
* 먼저 예상 위치로 이동한 후, 그 자리에서 기울기를 계산해 더 정확히 방향을 잡음
* 장점: 더 빠르고 정확한 수렴
* 비유: "앞으로 가볼 곳을 미리 내다본 후, 거기서 길을 찾음."

### 5. Adagrad
* 자주 업데이트되는 파라미터는 작은 학습률, 잘 업데이트되지 않는 파라미터는 큰 학습률을 줌
* 장점: 드문 특징에 강함
* 단점: 학습률이 점점 줄어들어 학습이 멈출 수 있음
* 비유: "많이 간 길은 천천히, 처음 가는 길은 빠르게 탐험."

### 6. RMSProp
* Adagrad의 단점을 개선
* 최근 기울기 정보만 반영해 학습률이 너무 빨리 줄어들지 않게 함
* 비유: "보폭을 줄이지만, 이전 상황도 같이 고려해서 안정적으로 걸음."

### 7. AdaDelta
* RMSProp의 또 다른 개선 버전
* 학습률을 직접 설정하지 않고, 자동으로 조정
* 비유: "걸음이 너무 작아져 멈추는 걸 방지."

### 8. Adam(Adaptive Moment Estimation)
* Momentum + RMSProp의 장점을 합친 최적화기
* 현재 가장 널리 사용되는 알고리즘 중 하나
* 장점: 학습률 조정 + 모멘텀 -> 빠르고 안정적
* 비유: "방향도 잘 보고, 보폭도 상황에 맞게 조절."

### 9. Nadam
* Adam + NAG
* Adam에 Nesterov 관성까지 결합
* 비유: "Adam의 빠르고 안정적인 걸음에, 미래 예측까지 더한 방식."

## 요약하면
* SGD: 빠르지만 불안정
* Momentum/NAG: 관성으로 더 매끄럽고 빠르게
* Adagrad/RMSProp/AdaDelta: 학습률을 자동 조정
* Adam/Nadam: 위의 장점을 다 섞은 최적화기 -> 오늘날 가장 많이 사용
