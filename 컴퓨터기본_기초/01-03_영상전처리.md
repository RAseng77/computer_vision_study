## 1. 영상 전처리(Image Pre-Processing) 개요
* 정의: 원본 이미지를 분석/학습하기 전에 품질을 향상시키거나, 중요한 특징을 더 잘 드러내도록 가공하는 과정.
* 왜 필요한가?
  * 현실 세계의 이미지에는 **조명,잡음,흐림,압축 손실,비나 먼지** 같은 다양한 문제가 있음.
  * 이런 요인들이 모델의 성능을 크게 떨어뜨릴 수 있음.
  * 전처리를 통해 데이터를 정규화/보정해주면 모델이 더 안정적으로 학습할 수 있음.
* 쉽게 말하자면, "이미지를 모델이 공부하기 쉽게 미리 다듬어주는 과정"

## 2. 영상 전처리의 영향
* 빛: 너무 어두우면 특징이 안 보임 -> 밝기 보정 필요.
* 압축: JPEG 같은 손실 압축은 아티팩트(깨짐)발생 -> 모델 혼란.
* 흐림: 초점이 맞지 않으면 경계(에지)가 사라짐 -> 인식률 저하.
* 빗방울/노이즈: 랜덤한 점/패턴이 모델의 특징 추출을 방해.
* 따라서 전처리는 환경적 요인의 부정적 효과를 줄이는 역할을 함.

## 3. 영상 밝기 전처리 기술
## (1) 히스토그램 평활화 (Histogram Equalization)
* 아이디어: 이미지의 픽셀 밝기 분포(히스토그램)를 고르게 만들어서 대비(contrast)를 향상.
* 어두운 영역은 더 밝게, 밝은 영역은 더 어둡게 -> 전체적으로 더 뚜렷해짐.
* 장점: 계산 간단, 대비 향상 효과 확실.
* 단점: 국부적(부분적)인 영역은 오히려 과도한 대비 발생 가능.

## (2) CLAHE(Contrast Limited Adaptive Histogram Equalization)
* 히스토그램 평활화의 개선판
* 이미지를 작은 블록 단위로 나눠서, 각 부분마다 히스토그램 평활화 적용.
* 단, 대비를 제한(Contrast Limited)해서 과도한 강화 방지.
* 장점: 지역적인 밝기/대비 문제 해결 가능 -> 의료영상, 저조도 영상에 많이 사용.

## 4. 딥러닝 기반 밝기 개선 기법
## (1) DCE-Net (Deep Curve Estimation Network)
* 입력 이미지의 픽셀 밝기를 보정하는 곡선(curve) 를 신경망이 직접 학습.
* 저조도 이미지를 입력하면, 모델이 곡선을 조정해 더 자연스럽게 밝기 향상.
## (2) EnlightenGAN
* GAN(Generative Adversarial Network)을 기반으로 저조도 이미지를 더 밝고 자연스럽게 생성.
* 기존 전처리 기법보다 훨씬 자연스러운 결과 제공
## 비교:
* 전통적 기법(히스토그램 평활화, CLAHE): 단순 수학적 조정 -> 인위적인 느낌
* 딥러닝 기법(DCE-Net, EnlightenGAN): 데이터 기반 학습 -> 사람 눈에 더 자연스럽고 우수

# DCE-Net (Zero-DCE)
## 아이디어
* 밝기 개선을 "이미지마다 다른 보정 곡선(curve)을 추정해 픽셀마다 적용" 하는 문제로 바꿔요.
  네트워크가 R/G/B 채널별 곡선 파라미터 맵을 예측하고, 이를 몇 번(보통 8회)반복 적용해 저조도 이미지를 점점 밝고 자연스럽게 만듭니다.

## 핵심 수식(직관형)
* 강조만 하자면, 입력 x (정규화된 픽셀값)에 대해 `x_{k+1} = x_k + a * (x_k^2 - x_k)`

* 형태의 곡선을 채널/픽셀마다, 여러번 적용. 여기서 a는 네트워크가 출력하는 "보정 강도"라고 보면 돼요.(단조성/미분가능성/범위 제약을 만족하도록 설계)

## 학습(라벨 불필요, Zero-reference)
* 정답 이미지(밝게 찍힌 짝 이미지)가 아예 필요 없음. 대신 다음과 같은 비참조(non-reference) 손실로 품질을 간접적으로 유도합니다.
  * 노출 제어 손실: 평균 밝기를 목표값(예:0.6) 근처로 유도
  * 색 균형 손실: R/G/B가 과도하게 치우치지 않게
  * 공간 일관성/매끄러움: 구조는 보존, 곡선 파라미터는 과도하게 요철 생기지 않게 이 조합덕분에 레퍼런스 없이도 꽤 안정적으로 학습됩니다.

## 장단점
* 가볍고 빠름, 데이터 준비 쉬움(짝 데이터 불필요), 오버-에디팅 적음
* 아주 극단적인 노이즈/색편향에는 추가 후처리(디노이징 등)가 유리할 때도...

# EnlightenGAN
## 아이디어
* 짝 데이터 없이(unpaired) "어두운 도메인 -> 일반 밝기 도메인"으로 매핑을 배우는 GAN. 생성기(보정 네트워크)가 출력을 만들고,
  전역 + 국소(global+local) 판별기가 "이게 정상 밝기 사진처럼 보이냐?를 감시합니다. 주의(attention)와 **자기-정규화 퍼셉추얼 손실(self-regularized perceptual loss)** 등을 섞어
  **내용/질감** 을 유지하게끔 유도합니다.

## 학습 (비지도/비쌍방향)
* CycleGAN처럼 사이클 일관성에 의존하지 않고, 정상 밝기 사진들을 "타깃 스타일"로 삼아 적대적 손실 + 퍼셉추얼/자기-정규화 규제로 훈련합니다. 데이터 준비가 쉽고 실사진 일반화가 좋은 편.

## 장단점
* 시각적 자연스러움, 질감/디테일 보존에 강함. 도메인 적응 유연
* GAN 특유의 불안정성/하이퍼파라미터 민감도, 때로 과증폭,노이즈 증폭 가
