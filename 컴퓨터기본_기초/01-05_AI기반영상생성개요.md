## 생성 모델

## VAE (Variational Autoencoder, 변분 오토인코더)
* 아이디어: 입력 데이터를 잠재공간(latent space)에 매핑했다가 다시 복원하는 Autoencoder 구조 + 확률적 추론(Variational inference)결합
* 핵심: 단순히 압축하는 게 아니라, 잠재공간 z가 정규분포 N(0,1)을 따른다는 제약을 둬서, 샘플링 가능하게 만듦.
* Loss:
  * $\mathcal{L}=\text{Reconstruction Loss}+\mathrm{KL}!\left(q_\phi(z\mid x),|,p(z)\right)$
  * 재구성 손실: 입력과 복원된 출력이 유사해야 함
  * KL Divergence: 인코더가 만든 분포 q(z|x)가 정규분포 p(z)와 비슷하도록 제약.
* 장점: 학습 안정적, 잠재 공간이 해석 가능
* 단점: 샘플링이 상대적으로 흐릿함(Blurry).

## Flow-based Models (Normalizing Flows)
* 아이디어: "복잡한 데이터 분포 = 단순한 분포(예: 정규분포)로부터 역변환을 통해 만들 수 있다."
* 핵심:
  * 단순 분포 z ~ N(0,I)에서 샘플링 -> 역함수f⁻¹ 적용 -> 복잡한 데이터 분포 x 얻음.
  * 반대로, 데이터를 잠재공간으로 보내는 f는 가역적이고 Jacobian determinant 계산 가능해야 함.
* Loss: 정확한 likelihood 계산 가능.
  * $\log p_X(x)=\log p_Z!\big(f(x)\big)+\log\left|\det\frac{\partial f(x)}{\partial x}\right|$
* 장점: 학습 후 likelihood 계산이 정확함 -> density estimation에 강함.
* 단점: 가역성과 jacobian 계산 제약 때문에 네트워크 구조가 복잡. (Glow, RealNVP 등)

## GAN (Generative Adversarial Network)
* 아이디어: 생성자(Generator)와 판별자(Discriminator)의 적대적 게임.
  * 생성자 G: z(랜덤 노이즈) -> 가짜 데이터 x_fake 생성.
  * 판별자 D: 입력이 진짜 데이터인지 가짜인지 판별
* 목표: G는 D를 속이고 싶고, D는 G를 잡아내고 싶음. (Minimax Game)
* Loss:
  * $\min_G,\max_D;\mathbb{E}{x\sim p{\text{data}}}![\log D(x)]+\mathbb{E}_{z\sim p(z)}![\log(1-D(G(z)))]$
* 장점: 매우 선명하고 사실적인 샘플 생성.
* 단점: 학습이 불안정(모드 붕괴, 발산 등)

## DDPM (Denoising Diffusion Probabilistic Models, 확산 모델)
* 아이디어: "이미지를 점점 노이즈로 오염시킨 다음(Forward Process), 그 반대 과정(Reverse Process)을 학습하면 데이터를 생성할 수 있다."
* Forward Process: 데이터에 점진적으로 가우시안 노이즈를 추가 -> 최종적으로 pure noise.
* Reverse Process: 노이즈에서 시작 -> 학습된 네트워크가 역으로 하나씩 노이즈 제거 -> 깨끗한 데이터 복원.
* Loss: 간단히 말해, 노이즈 예측 손실 (MSE).
* 장점: 학습이 안정적, 다양한 모달리티(이미지/텍스트/오디오)에 적용 가능.
* 단점: 샘플링 속도가 느림(수백~수천 step 필요). -> (해결: DDIM, Latent Diffusion, Stable Diffusion).
