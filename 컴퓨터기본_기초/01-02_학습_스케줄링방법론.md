## 학습 스케줄링(Learning Rate Scheduling)이란?
* 학습률(Learning Rate, LR)은 옵티마이저(Adam, SGD 등)의 핵심 파라미터.
* 처음부터 끝까지 고정된 학습률을 쓰면:
  * 초반에는 너무 느리게 -> 학습이 오래 걸림
  * 후반에는 너무 크게 -> 최적점 근처에서 왔다갔다하며 불안정
* -> 그래서 학습 도중 학습률을 조절하는 기법이 필요합니다. 이게 바로 학습 스케줄링

## 대표적인 학습 스케줄링 방법론
### 1. Step Decay
* 일정 에포크마다 학습률을 감소율(y) 만큼 줄임
* 공식: $ \eta_t = \eta_0 \cdot \gamma^{\lfloor t/s \rfloor} $
* (t=에포크, s=스텝 사이클, γ=감소율)

* 특징: 단순하고 안정적
* 예시: 30에포크마다 학습률을 0.1배씩 줄이기

### 2. Exponential Decay
* 학습률을 매 에포크마다 조금씩 지수적으로 줄임
* 공식: $ \eta_t = \eta_0 \cdot e^{-\lambda t} $
* (λ=감쇠 계수)

* 특징: 부드럽게 줄어듦

### 3. Cosine Annealing
* 학습률을 코사인 곡선처럼 줄였다가 다시 올리기도 함
* 특징: 한 번에 확 떨어지지 않고, 점점 느리게 줄어들어 안정적 수렴
* 최근 딥러닝 논문에서 자주 쓰임

### 4. Cyclical Learning Rate (CLR)
* 학습률을 아예 주기적으로 올렸다 줄였다 함.
* 아이디어: 너무 작은 학습률에 갇히지 않고, 새로운 최소점을 더 탐색할 수 있게.
* 대표 구현: One Cycle Policy

### 5. Plateau 기반 감소 (ReduceLROnPlateau)
* 검증 손실이 더 이상 줄지 않으면 자동으로 학습률을 낮춤
* 실전에서 자주 씀
* 과적합을 막고, 모델이 더 이상 학습하지 못할 때 마지막 "밀어주는 효과".

## PyTorch 예시 코드
```
import torch.optim as optim

optimizer = optim.SGD(model.parameters(), lr=0.1)

# StepLR: 30에포크마다 0.1배로 감소
scheduler = torch.optim.lr_scheduler.StepLR(optimizer, step_size=30, gamma=0.1)

for epoch in range(100):
  train(...)
  validate(...)

  scheduler.step() # 학습률 업데이트
```
