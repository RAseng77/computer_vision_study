# 네트워크 최적화

## Underfitting vs Overfitting
* Underfitting: 학습 데이터도 제대로 학습하지 못하여 새로운 데이터를 예측 못하는 상태
* Overfitting: 학습 데이터를 과도하게 학습하여 새로운 데이터를 예측 못하는 상태

## Batch Normalization
* Training 진행 중에, 각 층의 입력 배치를 평균과 분산 값을 이용하여 데이터 분포를 정규화하는 기법
* 활성화 Layer 전에 적용
* 장점: Training 안정화. Gradient 소실 문제 완화. 모델의 일반화 성능 향상
* 단점: Training 시간 증가. 미니 배치에서는 노이즈 생성 가능성 존재

## Dropout
* 신경망의 뉴런을 일정 확률로 제거(Drop)하는 네트워크 최적화 기법
* 장점: overfitting 방지. 앙상블 효과
* 단점: Training 시간 증가

## Learning Rate Scheduler
* Training 과정 중에 Learning rate 값을 조절하는 기법
* 다양한 종류의 Learning rate scheduler가 있으며, 각각의 기법에는 장단점이 존재

## Optimizer
* 모델의 Training 속도를 빠르게 하면서도 안정적이게 Training이 진행되도록 도와주는 역할. Parameter와 Gradient를 Optimizer에 전달하고, 파라미터를 업데이트하고 적용
* Optimizer 예시: SGD, Adagrad, RMSprop, Adam

## Activation Function
* 신경망의 이전 Layer에서 다른 Layer로 전달하는 신호의 세기를 정하는 역할
* 입력 신호를 비선형 변환을 적용하여, 복잡한 모델을 학습할 수 있음
